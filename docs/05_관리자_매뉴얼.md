# 관리자 매뉴얼

프로젝트12 통합관리 플랫폼(별하)의 화면별 사용 절차입니다. 역할은 본사 관리자, 지점장(원장), 멘토, 조교 네 가지이며 역할에 따라 보이는 메뉴가 다릅니다.

## 1. 시작하기

### 로그인
1. 브라우저에서 플랫폼 주소를 열고 아이디와 비밀번호를 입력합니다.
2. 비밀번호를 5회 틀리면 10분간 잠깁니다. 잠긴 동안은 맞는 비밀번호도 거부되니 10분 뒤 다시 시도하세요.
3. 조교는 로그인하면 바로 라운딩 홈으로, 나머지 역할은 대시보드로 이동합니다.

### 공용 태블릿에서 조교 바꾸기
1. 라운딩 홈 오른쪽 위 **전환** 버튼을 누릅니다.
2. 자기 이름을 고르고 PIN(숫자 4~6자리)을 입력합니다. PIN은 지점장이 설정 › 사용자에서 정합니다.
3. 전환 뒤 화면 위쪽에 이름이 바뀐 것을 확인합니다.

### 본사 관리자의 지점 전환
화면 위쪽 지점 이름을 누르면 지점 목록이 나옵니다. 고른 지점 기준으로 모든 화면이 바뀝니다.

## 3. 회원

### 회원 등록
1. **회원 › 회원 등록**.
2. 이름은 필수입니다. 상태를 **등록**으로 두면 좌석을 고를 수 있고, 이미 사용 중인 좌석은 회색으로 나옵니다.
3. 등록 시작일·종료일을 넣으면 대시보드에 만료 7일 전부터 표시됩니다. 단기 회원은 등록 유형을 **단기**로 둡니다.
4. **라운딩 특이사항**은 라운딩 목록에서 이름 아래에 항상 보이는 짧은 메모입니다(예: 매주 화 17시 학원 조퇴).
5. 본사가 커스텀 필드를 추가했다면 기본 정보 아래에 나타납니다.

### 좌석 변경과 퇴원
1. 회원 상세 › **좌석 · 상태** 탭.
2. 좌석은 빈 좌석만 고를 수 있습니다. 과거 라운딩 기록에는 당시 좌석번호가 그대로 남습니다.
3. 상태를 **퇴원**이나 **상담**으로 바꾸면 좌석이 자동으로 비고 라운딩·현황판에서 빠집니다. 기록은 타임라인에 남습니다.
4. 퇴원 후 1년(설정 가능)이 지나면 배치가 개인정보를 익명화합니다.

### 구글시트에서 한 번에 옮기기 (CSV 이관)
1. **회원 › CSV 이관**.
2. 구글시트에서 헤더 행부터 범위를 복사해 붙여넣거나 CSV 파일을 올립니다.
3. **미리보기**를 누르면 열 매핑이 자동으로 잡힙니다. 잘못 잡힌 열은 바꾸고 안 쓸 열은 "사용 안 함"으로 둡니다.
4. 검증 결과에서 빨간 행은 반영되지 않습니다. 대표적인 원인: 좌석번호가 지점에 없음(설정 › 좌석에서 먼저 추가), 같은 파일 안 좌석 중복, 이미 다른 회원이 쓰는 좌석, 이름 없음.
5. 이름 뒤의 `/S`는 단기 회원으로, `7월16~8월17일[33일]` 같은 기간은 등록기간으로 자동 변환됩니다.
6. 같은 이름에 같은 좌석(또는 같은 연락처)이면 기존 회원을 갱신하고, 아니면 새로 만듭니다. **N행 반영**을 누르면 끝납니다.

### 모의고사
1. **모의고사**에서 월·이름·응시료로 회차를 만듭니다.
2. 회차 화면에서 회원별로 신청 체크, 계열, 과목 조합, 결제일을 입력하고 **저장**합니다. 결제일만 넣으면 결제액은 응시료로 채워집니다.
3. 위쪽 요약에서 신청·결제·계열별 인원과 입금액을 확인합니다.

## 4. 집중관리일지 (상담)

1. **상담일지**는 회원 × 주차 그리드입니다. 기본은 최근 4주, **월별**을 누르면 그 달의 주차가 나옵니다.
2. 셀을 누르면 그 회원·그 주의 일지가 열립니다. 왼쪽이 원장(지점장) 열, 오른쪽이 멘토 열이며 각자 자기 열만 씁니다.
3. 상대에게 할 말은 아래 **코멘트**에 남깁니다. `@이름`을 쓰면 그 사람에게 알림이 가고, 행의 작성자에게도 알림이 갑니다. 잔디로 하던 학생 소통은 여기서 합니다.
4. 집중관리 회원의 일별 기록은 **집중관리 일지**에서 회원을 고르고 날짜 행을 누릅니다.
5. 회원 상세 › **타임라인**에 상담·코멘트·벌점·이슈·변경 이력이 시간순으로 모입니다.

## 5. 라운딩 (조교)

### 회차 진행
1. 라운딩 홈에서 **R{n} 시작**을 누릅니다. 진행 중인 회차가 있으면 **이어서 입력**이 보입니다.
2. 목록은 좌석 순이고 구역별로 나뉩니다. 모든 회원은 기본이 양호(a)이므로 **예외만** 누릅니다.
   - **b**: 잘하지는 못했지만 학원 일정 같은 사유가 있을 때.
   - **벌점**: 규칙을 고르면 점수가 자동으로 붙습니다. 오늘 이미 졸음 벌점이 있으면 "연속 졸음"이 먼저 선택됩니다.
   - **부재**: 자리에 없을 때.
3. 벌점 시트에서 메모를 남기고 **지점장에게 이슈로 보고**를 켜면 이슈함과 지점장 알림에 바로 들어갑니다.
4. 이름을 누르면 상세 시트가 열리고, 위쪽 검색창에 이름이나 좌석번호를 치면 바로 찾습니다.
5. **회차 완료**를 누르면 입력하지 않은 회원은 모두 a로 저장되고 요약(벌점·이슈·부재)이 나옵니다.
6. 통신이 끊기면 입력은 기기에 저장되고 **미전송 n건**으로 표시됩니다. 연결되면 자동으로 전송됩니다.

### 일별 체크
**일별 체크**에서 출석·플래너·영단어·점검완료를 같은 방식으로 입력합니다. 출석은 이름을 눌러 등원 시각과 전화 확인(CALL)을 기록합니다.

### 조회
**조회**에서 날짜를 골라 회원 × 회차 표와 벌점 합계를 봅니다. 회원 상세 › **라운딩 · 벌점** 탭은 한 회원의 주간 표입니다.

## 6. 현황판 (매장 모니터)

1. 지점장이 **설정 › 지점·현황판 › 링크 발급**을 누르면 주소가 한 번 표시됩니다. 복사해 모니터 PC 브라우저에 붙여넣습니다.
2. 현황판 위쪽 **전체화면** 버튼을 누르거나 브라우저 키오스크 모드로 띄웁니다. 1분마다 자동 갱신됩니다.
3. 색: 초록 a, 연두 b(점 표시), 빨강 벌점(점수), 흰색 미입력. 위쪽에 주간 벌점 합계와 벌점 규칙이 나옵니다.
4. 이름을 가리려면 설정 › 지점·현황판에서 **마스킹**을 켭니다(김*민).
5. 링크가 유출되면 **재발급**하세요. 이전 링크는 즉시 무효가 됩니다.

## 7. 이슈함과 알림

- 이슈는 라운딩에서 보고되거나 **이슈 등록**으로 직접 만듭니다. 지점장은 상태(접수 → 처리 중 → 해결)와 담당자를 바꾸고, 모두가 코멘트를 남길 수 있습니다.
- 상태를 바꾸면 보고자에게, 코멘트를 남기면 보고자·담당자·이전 코멘트 작성자에게 알림이 갑니다.
- 알림은 위쪽 종 아이콘과 **알림** 메뉴에서 봅니다. 항목을 누르면 해당 일지나 이슈로 이동합니다.

## 8. 식사주문

1. **식사주문 › 월별 신청**에서 회원 × 날짜의 중식(L)·석식(D)을 누릅니다.
2. 변경은 **전날 마감 시각(기본 23:59)** 까지만 됩니다. 마감이 지난 날짜는 회색이고, 지점장은 사유를 적고 바꿀 수 있습니다(감사 로그에 남음).
3. 토요일은 중식만, 일요일은 주문 불가가 기본이며 **설정**에서 바꿉니다. 휴무일도 설정에 적습니다.
4. **일별 발주**는 도시락 업체에 보낼 표이며 인쇄 버튼이 있습니다.
5. **월 정산**은 회원별 식수·금액·미수를 보여 줍니다. 결제일·결제액을 입력해 저장하면 완납으로 바뀝니다. 단가는 주문 시점 값이 유지되므로 단가를 바꿔도 지난 주문 금액은 그대로입니다.

## 9. 근무일지

1. 지점장이 **근무 › 타임·직원 설정**에서 타임(1타임 09:00~09:30 0.5h 등)과 직원별 근무 형태·시급을 정합니다. 주말 타임은 **주말**에 체크합니다.
2. 직원은 **내 근무**에서 오늘 근무한 타임을 체크하고 저장합니다. 초과근무는 시간과 사유를 함께 넣어야 합니다.
3. 지점장은 **일별 현황**에서 전체를 보고, 놓친 직원의 근무를 **대리 입력**할 수 있습니다.
4. 본사 관리자가 **확인**을 누르면 그 기록은 잠기고 월 집계의 본사확인 시간에 들어갑니다.
5. **월 집계**에서 근무자별 시간·초과·예상 급여를 보고 **급여 기초자료 CSV**를 내려받습니다. 본사는 지점별 합계도 봅니다.

## 10. 알림톡

1. 본사가 **설정 › 알림톡 템플릿**에 카카오 비즈메시지에서 승인받은 코드와 본문을 등록합니다. 변수는 `#{이름}` 형식이며 이름·지점·좌석은 자동으로 채워집니다.
2. 지점장은 **알림톡**에서 템플릿을 고르고 링크 같은 추가 변수를 입력한 뒤 대상(지점 전체 / 집중관리 / 직접 선택)과 수신자(회원 본인 / 학부모)를 고릅니다.
3. 미리보기를 확인하고 **N명에게 발송**을 누릅니다. 번호가 없는 회원은 자동으로 건너뜁니다.
4. **발송 이력**에서 상태를 보고, 실패 건은 **실패 재발송**으로 다시 보냅니다.

## 11. 설정

- **지점·현황판**: 하루 회차 수, 회차 시간표, 현황판 마스킹, 현황판 링크.
- **지점 관리(본사)**: 새 지점 생성(코드·이름·좌석 수·첫 지점장), 이름 변경, 비활성화.
- **사용자**: 계정 추가, 역할, 비밀번호 변경(10자 이상, 영문·숫자 포함), 조교 PIN, 비활성화. 지점장은 멘토·조교만 관리합니다.
- **좌석**: 번호·구역·순서, 일괄 추가.
- **벌점 규칙 / 현황판 항목**: 본사 기본값과 지점 오버라이드. 지점 규칙을 하나라도 만들면 그 지점은 지점 규칙만 씁니다.
- **커스텀 필드(본사)**: 회원·이슈 양식에 항목 추가. 삭제 대신 사용 해제로 숨깁니다.
- **메신저 연동**: 사내 메신저 인커밍 웹훅 주소와 구독 이벤트.
- **감사 로그**: 회원·이슈·설정·사용자의 변경 이력.

## 12. 자주 묻는 질문

- **회원을 등록했는데 라운딩에 안 보여요.** 상태가 **등록**이고 좌석이 배정되어 있어야 합니다.
- **좌석을 고를 수 없어요.** 다른 회원이 쓰고 있습니다. 회원 목록에서 그 좌석의 회원을 확인하세요.
- **조교가 회원 연락처를 못 봐요.** 의도된 동작입니다. 조교 역할에는 개인정보가 보이지 않습니다.
- **현황판이 안 열려요.** 링크가 재발급되었거나 지점이 비활성화된 경우입니다. 설정에서 다시 발급하세요.
- **식사 주문을 못 바꿔요.** 마감이 지났습니다. 지점장에게 요청하면 사유와 함께 변경할 수 있습니다.
- **근무를 수정할 수 없어요.** 본사 확인이 끝난 기록입니다. 본사에 확인 취소를 요청하세요.
